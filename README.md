# Kumiho

A phone-first messenger with no server you have to trust.

- **Post-quantum end-to-end encryption.** Hybrid X25519 + ML-KEM-768 handshake, then Signal's Triple Ratchet.
- **No phone number, email or username.** You add contacts face to face by scanning a single-use animated code (the Glyph), or by typing a short one-time code (SPAKE2) when there's no camera.
- **Three privacy modes per contact.** Fast (iroh, direct), Private (Tor via Arti) and Untraceable (Nym mixnet with cover traffic). The stricter of the two people's settings always wins, and the app never downgrades silently.
- **Offline delivery.** Messages wait in rotating Veilid mailboxes until the other person comes back.
- **Encrypted local storage.** SQLCipher, with the key wrapped by Secure Enclave, Keystore or TPM.

## Architecture

One Rust core holds every key and does all crypto, networking and storage. One Kotlin UI, built with Compose Multiplatform, runs on Android, iOS, Windows, macOS and Linux. The two meet through UniFFI bindings (generated by Gobley) that pass plain data, never keys.

```
kumiho/
  core/       Rust: identity, glyph, pairing, session, envelope, delivery, transport, storage, keystore, ffi
  app/        Compose Multiplatform UI (commonMain + platform code)
  mockup/     HTML mockup of the UI
```

## Build order

Each step ships something that works on its own.

1. CLI chat: two terminals, iroh + libsignal, keys exchanged by hand.
2. Storage and outbox: SQLCipher schema, retries, ACKs, sequence numbers.
3. Glyph v1: payload, renderer geometry, Rust decoder tested on photos.
4. Pairing: Glyph and typed-code (SPAKE2) pairing CLI to CLI, with emoji confirmation.
5. Veilid presence and mailbox.
6. Delivery core: packetizer, erasure coding, rotating mailboxes.
7. Nym Untraceable mode, cover traffic and the scheduler.
8. Android app.
9. Multi-device linking.
10. Windows and Linux apps.
11. Arti Private mode and the mode rules.
12. iOS and macOS apps.
13. Groups.
14. Outside security review before anyone relies on it.

## Building

```bash
cargo test            # core (needs Rust 1.80+)
gradle :app:run       # desktop app (needs JDK 17+ and Gradle 8.x)
gradle :app:desktopTest
```
